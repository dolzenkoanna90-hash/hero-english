# Hero English — Мой репетитор

Английский через супергеройские миссии по основным темам Spotlight 2, 3 и 4.

**Открыть сайт:** https://dolzenkoanna90-hash.github.io/hero-english/

Сайт работает без входа в ChatGPT и без платного API. Учебный помощник использует подготовленные объяснения и подсказки, а не подключённую языковую модель. Изображения, стили и задания находятся в этом репозитории; внешние шрифты не загружаются. Доступность github.io зависит от сети пользователя.

## Что есть

- 80 шагов по программе 2–4 классов: слова, слушание, письмо и понимание фраз.
- Подсказки после ошибки, адаптация сложности и повторение слабых тем.
- Кабинет родителя, прогресс и выбор текущей школьной темы.
- Изображения супергероев и отключаемая анимация (кнопка ✦).

## Перенос прогресса со старого сайта

1. На старом сайте откройте «Для родителя» → «Экспорт».
2. На новом сайте в том же кабинете выберите «Импорт» и сохранённый JSON.
3. Проверьте данные. Импорт заменяет результаты в текущем режиме нового сайта.

Разные адреса сайтов используют отдельные хранилища браузера. Результаты автоматически между ними не синхронизируются. На новом устройстве тоже нужен экспорт и импорт. Данные занятий в GitHub не отправляются. Не добавляйте экспорт прогресса, ключи, личные документы или PDF учебников в этот публичный репозиторий.

## Локальный запуск

Скачайте Code → Download ZIP, распакуйте и в папке выполните:

```sh
python3 -m http.server 4173
```

Откройте http://localhost:4173/. Простое открытие index.html через file:// не подходит для модулей JavaScript. Голоса для озвучивания зависят от браузера и устройства.

## Публикация

GitHub → Settings → Pages → Deploy from a branch → main → /(root).
Файл .nojekyll отключает обработку статических ресурсов Jekyll. Ссылки относительные, поэтому сайт работает в подпапке /hero-english/.

## Проверки

```sh
node --test tests/*.test.mjs
```

Изображения супергероев предоставлены владельцем проекта. Права на персонажей и изображения принадлежат соответствующим правообладателям. Полные сканы учебников здесь не публикуются.
